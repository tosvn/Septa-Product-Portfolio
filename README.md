# Abdulsalam Mudasiru — Developer Portfolio

A clean, responsive, recruiter-ready portfolio website designed around a dark studio palette (`#121316` / `#1E2028`) with warm amber accents (`#D97706`) to blend seamlessly with your portrait photo.

## Folder Structure

```text
portfolio/
├── index.html          # Main semantic HTML structure & sections
├── styles.css          # Custom scrollbar & card hover styles
├── script.js           # Project category filtering & clipboard toast
├── assets/
│   └── profile.png     # Your studio headshot
└── README.md           # Setup & deployment instructions
```

## Quick Start 

 **Local Preview:** Open `index.html` directly in any browser, or run a local server (`npx serve .` or VS Code Live Server).
